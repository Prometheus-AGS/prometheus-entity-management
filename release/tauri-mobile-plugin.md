# Tauri desktop and mobile plugin contract

The `v3-tauri-mobile-plugin` gate certifies the installable JavaScript/Rust
plugin boundary without treating a desktop test or native source file as
Android/iOS runtime proof.

## Public surface

`@prometheus-ags/entity-graph-tauri` exposes two related TypeScript surfaces:

- ergonomic command and lifecycle wrappers such as `createTauriGraphPlugin`,
  `platformPing`, and the event listener helpers;
- Rust-derived `generatedCommands`, `generatedEvents`, payloads, results, and
  event types generated by Tauri Specta v2.

The embedded `entity-graph-tauri` Rust crate exports `init()` as its primary
Tauri registration function. `EntityGraphPlugin::new()` remains an alpha
compatibility constructor. The npm tarball is the distribution owner for the
crate; crates.io publication is not implied.

The fail-closed public ledger is
`prometheus-entity-skills/_shared/references/tauri-library-exports.json`. It
records runtime names from `dist/index.mjs` separately from every exported
declaration name in `dist/index.d.ts`.

`src/generated-public.ts` is the handwritten structural facade over the
Rust-derived binding implementation. It preserves the generated runtime
objects while preventing an implementation-detail module specifier from
leaking into the public declaration graph. Strict packed NodeNext consumers
must type-check with `skipLibCheck: false`. Because this adjustment changes
declaration structure rather than exported names, the ledger remains 26 runtime
exports and 57 declaration exports.

## Capability boundary

`entity-graph-tauri:default` is read-only and grants:

- `allow-graph-get-entity`;
- `allow-graph-get-list`;
- `allow-graph-platform-ping`.

Every mutation, snapshot, and clear command requires an individual permission,
including `entity-graph-tauri:allow-graph-upsert-entity`. Tauri applies these
permissions through window/webview capabilities. Capabilities that target the
same principal merge authority, so broad overlapping files are not least
privilege.

## Persistence boundary

The Rust `GraphPluginState` is an in-memory IPC mirror. Its snapshot commands
store and retrieve JSON strings inside the current native process; they do not
establish restart durability. Applications requiring durable SQLite state use
the core `createTauriSqlPersistenceAdapter`. This gate makes no process-restart
or offline-sync claim for the native mirror.

## Evidence matrix

| Claim | Status | Evidence |
|---|---|---|
| Rust-derived command/event bindings are current | Implemented | binding generator `--check`, TypeScript build, runtime tests |
| Registered desktop plugin command executes through Tauri IPC | Implemented | `tests/fixtures/tauri-plugin-host` with `MockRuntime` |
| Missing capability rejects the command | Implemented | denied-webview host test |
| npm tarball is a usable Rust dependency | Implemented | extracted-candidate Cargo host test |
| Rust, permission, Android, and iOS sources are packaged | Implemented | tarball payload verifier |
| Android Kotlin bridge executes and rejects without permission | Implemented | hash-verified Samsung Android 16 physical-device receipts |
| iOS Swift bridge executes and rejects without permission | Implemented | hash-verified iPhone 17/iOS 26.5 simulator receipts |
| Complete Tauri application UX and restart/offline flow | Downstream | `v3-tauri-universal-example` |

Run the implemented host boundary with:

```bash
pnpm run verify:tauri-plugin
pnpm run bdd:tauri-plugin
```

Android/iOS runtime receipts follow
[`tauri-mobile-device-lane.md`](tauri-mobile-device-lane.md) and are retained
under the plugin change's device evidence directory. `examples/coverage.json`
records the plugin bridge gate as implemented. Stable 3.0.0 remains open for
the separately owned universal application, aggregate certification, and
publication gates.

## What this does not certify

- a full desktop/mobile showcase, rendered accessibility, or device UX;
- process-restart persistence, synchronization, or remote server availability;
- registry authority, provenance, release-candidate recovery, or npm `latest`.
