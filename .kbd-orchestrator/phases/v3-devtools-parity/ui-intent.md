# DevTools UI intent

The DevTools must detect development mode and automatically show a floating action button. Developers must be able to turn the feature off and on easily when it obscures the application. The inspector must provide world-class UI/UX for the entity graph, entity events, the views currently displaying each entity, dirty entities with their canonical originals and uncommitted live values, and entity update history.

The design must be grounded by the available Anthropic-origin frontend design guidance, Vercel React performance guidance, and current Vercel web-interface rules. It must then receive isolated adversarial review and sycophancy correction. The normal production package path must remain free of the heavy inspector.
