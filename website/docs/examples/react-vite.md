# React/Vite scenario tour

The showcase proves graph identity and REST/GraphQL population, optimistic
confirm and exact rollback, relationship invalidation, local/remote/hybrid
views, realtime coalescing, offline persistence and convergence, Suspense/error
containment, DevTools, keyboard behavior, and accessibility. Run the focused
gate with `pnpm run verify:vite-react19`.

Screenshots and their immutable receipts are cataloged in
[Evidence](../evidence/index.md); gallery assets are never treated as proof
without the matching scenario and source SHA.
