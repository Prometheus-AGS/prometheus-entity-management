# Five applications, one scenario contract

All showcases use the shared Project/User/Task/Comment/Activity domain and the
capabilities in `examples/coverage.json`. “Implemented” records a bounded source
and evidence claim; registry publication is reported separately. Flutter is
public on pub.dev and all twelve npm packages are public at stable `3.0.4`; no
app-store release is claimed.

| Example | Current boundary |
| --- | --- |
| React 19 / Vite 8 | implemented; production browser evidence |
| Next.js App Router | implemented; packed consumer and browser evidence |
| Agentic A2UI | implemented; policy, protocol, desktop/mobile browser evidence |
| Flutter / Riverpod | implemented; host/golden plus Android emulator and iOS simulator evidence |
| Tauri universal | implemented; macOS, Android emulator, iOS simulator evidence |

- [Flutter/Riverpod scenario tour](flutter-riverpod.md)
