# Populate the graph from any transport

Adapters translate external events into typed graph operations. They own
networking, authentication boundaries, checkpoint state, retries justified by
observed failures, and realtime subscriptions. Hooks never contact external
services directly.

- [Flint Realtime Fabric](flint-realtime-fabric.md)
- REST and GraphQL
- WebSocket and Supabase Realtime
- PGlite and Loro local-first convergence
- A2A and policy-controlled A2UI
- Tauri native adapters and optional Flutter FFI
