# Framework bindings

Every binding follows the same flow: **View → Hook/ViewModel → Store → Service
→ External**. React and Flutter have complete progressive tracks. Svelte,
Solid, Alpine, Web Components, and HTMX expose smaller adapters over the same
core contract.
