# Evidence before claims

Public screenshots are allowlisted records, not decorative proof. Each asset
must identify its scenario IDs, caption, alternative text, source path and SHA,
verification receipt, dimensions, certification status, and SHA-256. Blank
captures, icons, internal absolute paths, secrets, and raw failure diffs are
excluded from product galleries.

The evidence manifest is generated and verified during the examples and
integration documentation gate. Until then, source receipts remain under the
phase evidence directory and no untracked image is published.
