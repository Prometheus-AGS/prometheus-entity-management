# Prometheus Entity Management brand provenance

The entity-node/edge mark and social card were created for this repository on
2026-08-05. They use the Prometheus Ember tokens already documented by this
repository: light Ember `#E04E28`, dark Ember `#FF6A3D`, and charcoal
`#0B0F14`. The SVG sources remain editable and include accessible titles and
descriptions; there is no KnowMe or Flint product mark in the public site.

Typography is self-hosted from the built documentation artifact through the
following OFL-1.1 licensed Fontsource packages, pinned in `website/package.json`
and `pnpm-lock.yaml`:

- `@fontsource-variable/space-grotesk@5.3.0`
- `@fontsource-variable/inter@5.3.0`
- `@fontsource-variable/jetbrains-mono@5.3.0`

Fontsource package metadata and license files are the distribution provenance.
No third-party font CDN is requested by the site.
