commands.rs

Every #[tauri::command] exposed by the entity-graph plugin.

Every command is annotated with #[specta::specta] and registered in the tauri-specta collection so TypeScript bindings are generated from Rust.

Naming convention: Tauri surfaces these as plugin:entity-graph-tauri|<fn_name> matching the plugin name registered in lib.rs.
