lib.rs

Tauri v2 entity-graph plugin entry point.

Register in your app’s lib.rs:

ⓘ
use entity_graph_tauri::init;

tauri::Builder::default()
    .plugin(init())
    .run(tauri::generate_context!())
    .expect("error while running tauri application");

The desktop implementation keeps graph operations in Rust. Android and iOS additionally register a tiny native plugin used by host/device smoke lanes.
