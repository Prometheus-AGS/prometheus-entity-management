    applyStaleActionRejection

    • applyStaleActionRejection(input: unknown): void

      Apply what a server returned when it rejected an action as stale: the operations since the version the client held, with the versions they bring each surface to. They go through the same ordering and limits as any activity, so a repeated rejection changes nothing. A rejection that carries no operations cannot repair the surface, so it requests a resync. The wire shape is documented in stale-action.ts.

    exportSurfaceMessages

    • exportSurfaceMessages(
          surfaceId: string,
          options?: SurfaceExportOptions,
      ): PrometheusA2uiSurfaceExport

      Export a surface as messages that rebuild it in a fresh runtime: catalog, theme, sendDataModel, every component (with its own catalog where it differs), the data model and, for a v1.0 surface, its wantResponse and responsePath action metadata. Components unreachable from root are pruned and reported in orphans; pass { pruneOrphans: false } to keep them. Exporting the rebuilt surface again yields the same messages.

    retryAction

    • retryAction(actionId: string): Promise<boolean>

      Resend an executed action under the same actionId. The runtime owns the retry: a host that resent on its own would mint a new id and defeat the server's idempotency. The resent envelope is the original, so its heldVersion and data model are those from when the action fired. Returns false when the id is unknown (never emitted here, or forgotten past the retained-action bound) or no onActionEnvelope handler is installed.

    setLimits

    • setLimits(overrides: Partial<PrometheusA2uiLimits>): void

      Change some limits while the runtime is running. Applies to future calls only and never evicts a surface already held. A cap lowered below what is held refuses calls that would grow past it, but still allows calls that shrink or hold steady, so the host can get back under the cap.
