    Class SurfaceModel<T, F>

    State model for a single UI surface.

    Coordinates data binding, component state, and action dispatching.

    Type Parameters

    • T extends ComponentApi = ComponentApi

      Concrete type of the ComponentApi from the catalog.

    • F extends FunctionApi = FunctionImplementation

      The catalog's function kind. Every state and messaging capability of the surface works with a schema-only catalog (SurfaceModel<T, FunctionApi>); only node-tree resolution needs implementations.

      Type Parameters

      • T extends ComponentApi<ZodTypeAny> = ComponentApi<ZodTypeAny>

        Concrete type of the ComponentApi from the catalog.

      • F extends FunctionApi = FunctionImplementation

        The catalog's function kind. Every state and messaging capability of the surface works with a schema-only catalog (SurfaceModel<T, FunctionApi>); only node-tree resolution needs implementations.

      Parameters

      • id: string

        Unique identifier for this surface.

      • defaultCatalog: Catalog<T, F> | undefined

        Catalog that resolves components and functions that do not name a catalog explicitly. From v1.0 a surface may have none, in which case every component and function call must name its catalog.

      • OptionalavailableCatalogs: ReadonlyMap<string, Catalog<T, F>> | null

        Every catalog a payload on this surface may select by catalogId, keyed by that identifier. The message processor populates it with the catalogs whose protocol version is compatible with the surface's own. Passing a plain object here is deprecated: it selects the pre-1.0 argument order (id, catalog, theme, sendDataModel?, dataModel?), in which the object is the theme and the two arguments after it shift.

      • Optionaltheme: any

        Theme to apply to this surface.

      • OptionalsendDataModel: boolean

        Whether the renderer sends the full data model with actions.

      • OptionaldataModel: DataModel

        Optional custom DataModel instance. If provided, the SurfaceModel assumes full ownership of its lifecycle and will dispose it when dispose() is called.

      • OptionalrootId: string

        Identifier of the root component on this surface (defaults to 'root').

      • Optionalmetadata: A2uiMetadata

        Optional surface-level metadata for vendor extensions.

      • OptionalprotocolVersion: string

        Protocol version of the surface. Defaults to the default catalog's version; surfaces without a default catalog pass it explicitly.

      Returns SurfaceModel<T, F>

    resolveCatalog

    • resolveCatalog(catalogId: string | undefined, subject?: string): Catalog<T, F>

      Resolves the catalog that an item on this surface uses.

      An item that names a catalog uses that entry of availableCatalogs; one that names none uses the defaultCatalog. Both the message processor, when validating a payload, and DataContext, when running a function call, resolve catalogs through this method.

      Parameters

      • catalogId: string | undefined

        Catalog the item names, or undefined when it names none.

      • Optionalsubject: string

        Description of the item for error messages, such as Function call 'formatDate'.

      Returns Catalog<T, F>

      The catalog the item resolves to.

      Throws

      If the named catalog is not available on this surface, or if the item names none and the surface has no default catalog.
