    Interface UseEntityViewOptions<TEntity>

    Configure a live view over a base list: filter/sort/search in JS when data is complete, or compile the same spec to remote params when not. baseQueryKey identifies the underlying id list in the graph; the hook may create additional keys for remote result sets.
