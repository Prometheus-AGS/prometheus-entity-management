    Interface EntityDiffClassNames

    entity-diff.tsx — EntityDiff: renders a field-level diff of an entity.

    Supports two modes:

    • Uncontrolled: manages its own useEntityDiff state (showControls=true default)
    • Controlled: accepts an external diff result via the diff prop (used by EntityApproval to share a single hook instance)

    Reuses core time-travel (recordGraphSnapshot / restoreGraphSnapshot) through the useEntityDiff hook layer.
