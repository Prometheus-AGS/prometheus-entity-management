    Interface CRUDState<TEntity>

    Everything a CRUD screen needs: composed list view, selection, detail subscription, relation joins, edit/create buffers, and mutating actions. applyOptimistic is the escape hatch to mirror the buffer into patches for instant sliders/toggles without committing save yet.
