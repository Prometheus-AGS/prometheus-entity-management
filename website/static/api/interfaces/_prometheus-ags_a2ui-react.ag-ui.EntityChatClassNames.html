    entity-chat.tsx — EntityChat: a headless + minimal-shell chat component.

    Architecture:

    • Delegates all session management to useChatSession (which calls applyAgUiSnapshot / applyAgUiDelta — store writes — never directly).
    • Renders a minimal but intentional chat UI: message list + input form.
    • All styling is done via className overrides so consumers can bring Tailwind, CSS modules, or any other styling layer.

    Layering: Component → useChatSession hook → applyAgUiSnapshot/Delta (store). No direct store access from this file.
