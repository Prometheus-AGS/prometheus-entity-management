    Interface GraphState

    Canonical Zustand store: entities (server truth), patches (UI-only overlay), lists (id order + list meta), and entityStates (per-entity fetch state). Framework bindings subscribe to the vanilla store; stores, adapters, and engines can read it synchronously through graphStore.getState().
