    entity-interrupt-approval.tsx — human decision on an AG-UI 1.0 interrupt.

    Presentational: it shows one interrupt and reports approve, deny or edit-before-approve to onDecide. useChatSession().resolveInterrupt takes that decision to the A2UI action policy, so an approval is still authorized, executed and audited like any other action, and then resumes the run.

    Layering: Component → useChatSession (hook) → ChatConversationStore (store).
