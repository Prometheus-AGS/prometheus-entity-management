    Interface PrometheusA2uiLimits

    Resource limits for agent-generated UI arriving at the runtime.

    Trust boundary: A2UI messages come from an agent or a server the host does not control. Without caps, one faulty or hostile producer can exhaust the browser's memory or CPU. The official @a2ui/web_core processor enforces no resource caps of its own, so the runtime does.

    Defaults are provisional estimates, not measurements. A host that needs more room raises specific limits; nothing is silently truncated.
