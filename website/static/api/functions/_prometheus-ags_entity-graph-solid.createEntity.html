    Function createEntity

    • createEntity<TRaw, TEntity extends object>(
          opts: CreateEntityOptions<TRaw, TEntity>,
      ): CreateEntityReturn<TEntity>

      Creates a fine-grained SolidJS reactive primitive for a single entity.

      • Uses createResource as the async driver so Suspense and ErrorBoundary boundaries work naturally.
      • Subscribes to the Zustand graph with graphStore.subscribe and mirrors the merged entity into a createStore-backed signal for fine-grained SolidJS reactivity (only the changed field triggers updates).
      • Registers / unregisters a subscriber token with the core engine so idle entities stop background revalidation when no components are observing them.

      Example

      const invoice = createEntity({
        type: "Invoice",
        id: () => props.invoiceId,
        fetch: (id) => api.get(`/invoices/${id}`),
        normalize: (raw) => ({ ...raw, id: raw.invoice_id }),
      });

      return (
        <Show when={!invoice.isLoading()} fallback={<Spinner />}>
          <p>{invoice.data()?.amount}</p>
        </Show>
      );
